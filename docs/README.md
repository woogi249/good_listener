# 문서 안내

현재 OpenAI-only 0.1.x 제품의 운영 기준은 아래 세 문서다.

- `operations.md`: 설치, 시작 전 점검, 백업, 삭제, 장애 대응, 배포·롤백
- `privacy-and-data.md`: 외부 전송, 동의, 영구 보존, 암호화와 접근 경계
- `release-checklist.md`: 기능, 품질, 보안, Windows 패키징 출시 기준

`decisions/`, 날짜가 붙은 `handoff-*.md`, `openai-support-application.md`, 루트의 `outputs/`는 이전 EXAONE·로컬 Whisper·CLI 기반 MVP의 연구 및 인수인계 기록이다. 역사적 맥락을 보존하기 위해 남겨 두지만 현재 실행법, 보안 정책, 모델 선택, 보존 정책의 근거로 사용하지 않는다. 내용이 충돌하면 위의 0.1.x 운영 문서와 루트 `README.md`가 우선한다.
