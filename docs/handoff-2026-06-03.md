## 이어서 볼 포인트

1. 실제 마이크 발화가 trigger에 걸리는지 브라우저에서 확인한다.
   - 잘 걸리는 예:
     - `비용이 30만 원 정도 나올 것 같습니다.`
     - `제가 내일까지 결과를 정리해서 공유하겠습니다.`
     - `그럼 이 안으로 확정하죠.`
     - `이 문제를 어떻게 풀지 대안이 필요합니다.`
   - 단순한 "작동 안 하는 것 같아요"는 현재 규칙상 패널 호출이 안 걸릴 수 있다.

2. EXAONE 호출 지연이 길다.
   - 테스트에서 `fast-fallback`까지 포함해 대략 15~23초가 나왔다.
   - 실시간 UX 기준으로는 thinking 경로 timeout을 줄이거나, 기본을 non-thinking으로 바꾸는 튜닝이 필요할 수 있다.

3. UI Director도 예산과 호출 지연에 영향을 준다.
   - 패널 호출 뒤 별도 EXAONE 호출이 한 번 더 나갈 수 있다.
   - latency가 문제면 `layoutArbiterToggle`을 끄거나 UI Director 호출 빈도를 제한하는 후속 작업을 고려한다.

4. API 키 관리.
   - 현재는 process env만 사용.
   - 지속 실행이 필요하면 `.env`에 `EXAONE_API_KEY` 또는 `API_KEY`를 넣을 수 있지만, 절대 Git에 커밋하지 말 것.

5. STT 품질.
   - 기본 모델은 여전히 `small`, chunk는 `DEFAULT_STT_CHUNK_S = 4`.
   - 한국어 인식률이 낮으면 `medium` 이상, chunk 8초, 또는 Whisper API 옵션을 별도 provider로 추가하는 방향을 검토한다.
