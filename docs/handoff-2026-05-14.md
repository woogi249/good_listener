## 제품 방향

이 앱은 회의록 앱이 아니라 **회의 중 공용 화면에서 흐름을 보조하는 4패널 AI**다.

- A 요약: 최근 흐름 요약
- B 팩트체크: 수치, 일정, 고유명사, 기술 주장 확인
- C 아이디어: 교착 또는 반복 논점에서 대안 제시
- D 반박: 합의/결정 신호 직후 리스크 지적

사용자 요청에 따라 중요한 내용은 `importance=1~3`으로 판단하고, UI에서 중요도가 높을수록 글자를 더 크게 보여준다.

## 알려진 한계

1. STT 고유명사 인식은 개선됐지만 완전하지 않다. 실제 팀에서 자주 쓰는 모델명, 프로젝트명, 사내 약어를 준비 폼이나 `prompts/domain-ai.txt`에 계속 추가해야 한다.
2. 마이크 STT는 4초 고정 청크다. VAD 기반 발화 경계 감지는 아직 없다.
3. 패널 트리거는 룰 기반 초안이다. 실제 회의 로그로 false positive/false negative 튜닝이 필요하다.
4. CLI 호출 레이턴시가 회의 중 UX를 흔들 수 있다. 큐/우선순위는 기본 구조만 있고 p95 측정은 아직 부족하다.
5. Action Item / Decision Log 사후 리포트는 아직 없다.
6. 동의 화면, 전체 로컬 전용 모드, 민감정보 필터는 아직 없다.
7. 패키징/Electron/Docker는 아직 없다.
8. PowerShell에서 한글을 직접 pipe로 넘기는 테스트는 인코딩이 깨질 수 있다. 앱 경로와 Python 내부 처리는 UTF-8 기준으로 동작한다.
