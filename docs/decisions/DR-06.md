# DR-06: 4패널 UX / 인지부하 설계

**상태:** 작업 가설 (Phase 0 spike 전)
**작성일:** 2026-04-19
**선행 조건:** DR-03 (STT 모드/자막 실시간성), DR-05 (트리거 빈도)

---

## 1. 가정 (Assumption)

- 팀 공용 디스플레이: 회의실 TV/모니터 (50~75인치, 시야 거리 3~5m). 개인 노트북 화면 용도가 아님.
- DR-03에서 확정된 STT 2~5초 청크 방식으로 실시간 자막 스트리밍이 가능함을 전제로 한다. 자막 바는 STT 출력을 직접 소비하는 영역이다.
- DR-05에서 분당 전체 트리거 ≤ 2회 통과 기준을 전제로 한다. 패널 갱신은 30~60초 간격으로 발생하며, 동시 4개 패널 갱신은 예외적 상황이다.
- CLAUDE.md: 각 패널 출력 1줄 50자 엄수. 이 제약은 이 DR에서 변경할 수 없으며, 변경이 필요한 경우 섹션 5 Fallback에 명시된 재협상 절차를 따른다.
- 사용자는 회의 중 패널을 힐끗(glance) 보는 패턴을 취한다. 장시간 주시를 전제로 한 정보 밀도는 금지한다.
- 픽셀 단위 와이어프레임, 컬러팔레트 확정, CSS 구현은 이 DR의 범위 밖이다(Non-Goal). 원칙과 측정 가능 기준만 확정한다.
- 의존성: DR-03 (자막 바 스트리밍 모드), DR-05 (트리거 빈도 및 갱신 주기). 이 DR의 결론은 Frontend Developer 구현(AGENTS.md Phase 1)의 설계 기준이 된다.

---

## 2. 작업 가설 (Working Hypothesis)

**4분할 고정 그리드 + 갱신 하이라이트 + 상단 실시간 자막 바**:

- 상단 좁은 자막 바 (화면 높이의 약 15%) — STT 실시간 스트리밍, 최근 2~3발화 표시. 자막과 AI 분석의 시각적 원천 구분.
- 하단 4분할 고정 그리드 (화면 높이의 약 85%) — 각 셀에 패널 1개. 레이아웃 시프트 없음.
- 패널 배치 순서 (왼쪽 상단 → 시계방향): **A 요약 / B 팩트체크 / D-3 반박 / C 아이디어**.
- 갱신 시 시각 피드백: 1초간 배경색 서서히 페이드(플래시 아님). 깜빡임(blink/flicker) 금지.
- CLS(Cumulative Layout Shift) = 0. 고정 그리드이므로 갱신 시 셀 크기·위치 불변.
- 각 패널 셀 하단에 마지막 갱신 시각 표시 ("N초 전"). stale 오인 방지.
- 패널 on/off 토글 지원: 3/2패널 축소 모드. Fallback 또는 팀 선호도에 따라 활성화.

이 가설은 Phase 0 spike 물리 확인(시인성 체크리스트) 및 모의 회의 정성 평가 후 확정 또는 기각된다.

---

## 3. 이유 (Rationale)

**4분할 고정 그리드 선택 근거**

갱신마다 레이아웃이 이동하면 시선 추적 부하가 급증한다(Nielsen Norman Group, "Change Blindness in UI"). 고정 그리드는 각 패널의 위치를 장기 기억에 등록시켜, 힐끗 보기만으로 어느 영역에 시선을 보낼지 결정할 수 있게 한다. 회의 중에는 화면보다 발화자에게 시선이 가있는 시간이 더 길기 때문에, 패널 위치의 예측 가능성이 정보 전달 효율을 결정하는 핵심 변수다.

**왼쪽 상단 요약(A) 배치 근거**

한국어와 서양어 모두 시선은 왼쪽 위에서 시작한다(F-패턴, Nielsen Norman Group). 요약 패널은 "현재 회의가 어디쯤 왔는가"를 가장 먼저 전달해야 하는 정보이며, 힐끗 보기의 첫 착지점에 배치하는 것이 자연스럽다.

**1줄 50자 제약의 인지부하 근거**

성인 읽기 속도 기준 300자/분 = 5자/초다. 50자를 힐끗 보기(2~3초)로 완독하려면 16~25자/초가 필요하나, 주변 시야와 단속 운동을 고려하면 큰 글자 50자는 2초 내 인식 가능하다. 이 제약은 CLAUDE.md에서 외부 확정된 값이지만, glance 패턴 기준에서도 정당화된다.

**페이드 vs 깜빡임 구분 근거**

WCAG 2.3.1 기준, 초당 3회 이상 플래시는 광과민성 발작 위험이 있다. 1초 페이드는 이 기준을 명백히 벗어나며, 주의를 환기하는 동시에 시각 자극을 최소화한다. 깜빡이는 알림은 회의 중 인지 방해 요소로 작용하여 발화 집중을 해친다.

**자막 바 분리 근거**

STT 원문과 AI 분석 결과를 같은 영역에 혼합하면 정보 원천이 불명확해져 팩트체크 패널(B)의 신뢰도 판단에 혼선을 준다. 자막 바를 물리적으로 분리하면 "이것은 사람이 말한 것, 저것은 AI가 분석한 것"이라는 구분이 레이아웃 차원에서 명확해진다.

**마지막 갱신 시각 표시 근거**

DR-05의 쿨다운(30~120초)으로 인해 패널이 수분간 갱신되지 않을 수 있다. 갱신 없는 패널을 보고 "AI가 멈췄나?"로 오인하는 것은 회의 흐름을 방해하는 불필요한 인지 비용이다. "3분 전 갱신"과 같은 상태 표시는 이 혼선을 제거한다.

## 4. 검증 방법 (Verification) — 숫자 강제 예외, 체크리스트 + 프록시 지표

### 프록시 지표 (측정 가능)

| 항목 | 기준 | 측정 도구 |
|------|------|----------|
| 텍스트-배경 대비율 | WCAG AAA ≥ 7:1 | axe-core / Chrome DevTools Accessibility |
| 최소 글자 크기 (3m 거리, 50인치 기준) | 48px 이상 | CSS 검사 + 각도 계산 (시각 0.5° 이상) |
| CLS (Cumulative Layout Shift) | ≤ 0.0 (고정 그리드) | Lighthouse / web-vitals 라이브러리 |
| 프레임 드롭 (페이드 애니메이션 중) | 전체 프레임의 1% 미만 | Chrome DevTools Performance 탭 |
| 색각이상 시뮬레이션 통과 | Deuteranopia·Protanopia 조건에서 4패널 구분 가능 | Sim Daltonism 또는 Chrome DevTools 렌더링 시뮬레이션 |

**통과 기준**: 프록시 지표 5항목 전체 통과.

### 시인성 체크리스트 (Phase 0 spike — 물리 환경 직접 확인)

- [ ] 50인치 TV, 시야 거리 3m 환경에서 1줄 50자 전체를 2초 내 판독 가능
- [ ] 회의실 형광등 및 자연광(햇빛) 혼재 조건 모두에서 텍스트-배경 대비 유지
- [ ] 4패널 중 한 패널만 갱신될 때 어느 패널이 바뀌었는지 2초 내 식별 가능
- [ ] 자막 바가 4분할 그리드 패널 영역을 가리거나 겹치지 않음
- [ ] 패널 on/off 토글이 1클릭으로 접근 가능하며 현재 상태(활성/비활성)가 명확히 표시됨
- [ ] 각 패널에 마지막 갱신 시각("N초 전")이 표시되며 실시간으로 갱신됨

**통과 기준**: 체크리스트 6항목 전체 통과.

### 정성 평가 (3~5명 모의 회의 후 구두 질문)

- "정보 과부하로 느꼈는가?" (Yes/No) — 5명 중 3명 이상 No이면 통과
- "어느 패널이 가장 주의를 빼앗겼는가?" — 특정 1개 패널에 응답이 80% 이상 집중되면 배치·강조 방식 재검토
- "자막 바가 대화에 방해가 됐는가?" (Yes/No) — 5명 중 4명 이상 No이면 통과

**최종 통과 기준**: 프록시 지표 5/5 통과 AND 시인성 체크리스트 6/6 통과 AND 정성 과부하 질문 3/5 이상 No.

## 5. 탈락 시 대안 (Fallback)

**정성 평가 — 정보 과부하 판정 (Yes > 2/5명)**

- 플랜 A: 패널 3개로 축소. Ideator(C)를 기본 OFF로 설정, 사용자 토글로만 활성화. DR-05 트리거 설정과 함께 조정 필요.
- 플랜 B: 갱신 주기 확장. DR-05 쿨다운 공식의 계수를 `3×` → `5×`로 상향하여 화면 변화 빈도 자체를 줄임. DR-05와 공동 재조정 필요.

**시인성 체크리스트 — 3m 거리 판독 실패**

- 글자 크기 48px → 60px로 승격.
- 동시에 패널당 출력 50자 → 35자로 축소.

> ⚠️ **CLAUDE.md 최상위 제약 재협상 필수 (CONSISTENCY.md T-04)**
> 50자 제약은 CLAUDE.md의 "UI 패널 출력은 **절대 임의 확장하지 않음.** 1줄/50자 제약 엄수" 규칙에서 파생된 최상위 제약이다. 35자로 축소하는 것도 "임의 변경"에 해당하므로 Fallback 진입 전 **반드시 사용자에게 제약 변경 승인을 받아야 한다**. 대안 우선 시도:
> - (우선) 글자 크기만 60px로 승격, 50자 유지 → 패널 셀 높이 확대 허용 검토
> - (차선) TV/시야 거리 조정 권고 (DR-00c 운영 가이드 연동)
> - (최후) 35자 축소 — 사용자 승인 필수

**프록시 지표 — CLS > 0 관찰**

- CSS Grid 고정 구현 방식을 재검토. 패널 내부 콘텐츠 교체 시 컨테이너 높이가 변동되지 않도록 `min-height` 고정 또는 absolute 레이아웃 전환.

**프록시 지표 — 형광등 반사로 대비 기준 미달**

- 다크 모드를 기본값으로 전환. 동시에 회의실 조명 배치 권고 가이드를 운영 문서에 추가.

**프록시 지표 — 색각이상 시뮬레이션 미통과**

- 색상 의존 구분 제거. 패널 구분에 아이콘 또는 텍스트 레이블(패널명 상단 고정)을 추가하여 색상 없이도 패널 식별 가능하도록 변경.

**영향받는 DR**

- **DR-03**: 자막 바 스트리밍 모드 확정 필요. 자막 바 제거 또는 축소 시 DR-03의 실시간 출력 경로 변경 가능성 있음.
- **DR-05**: 정보 과부하 탈락 시 갱신 빈도 재조정이 필요하므로 DR-05 트리거 쿨다운 재협상 필요.
- **CLAUDE.md**: 3m 판독 실패 Fallback에서 50자 → 35자 축소 시, CLAUDE.md 최상위 제약 변경이 필요하며 이는 사용자 승인 후에만 진행 가능.
