## 이 리포지터리가 프로그램에 적합하다고 생각하는 이유

good-listener는 청각 장애인과 난청 사용자가 회의 중 흐름을 놓치지 않도록 한국어 음성을 실시간 전사하고, 요약·팩트체크·아이디어·리스크를 4패널로 보여주는 접근성 도구입니다. 아직 공개 초기라 stars/forks/downloads 지표는 거의 없지만, FastAPI/WebSocket UI, 로컬 Whisper STT, API/CLI 분석 경로, 설계 결정문까지 갖춘 MVP가 있습니다. 오픈소스로 공개해 비용 부담 없이 회의 접근성 도구를 개선하려 합니다.

## 프로젝트에서 API 크레딧을 사용할 계획

API 크레딧은 한국어 회의 전사 후 롤링 버퍼 기반 요약, 팩트체크, 아이디어 제안, 결정 리스크 분석 품질을 검증하는 데 사용하겠습니다. 로컬 Whisper로 음성 처리를 우선 수행하고, 외부 API에는 필요한 짧은 텍스트 문맥만 보내 개인정보 노출과 비용을 줄입니다. 다양한 회의 샘플에서 지연 시간, 정확도, 호출량을 측정해 청각 장애인이 실제 회의에서 사용할 수 있는 응답 속도와 안정성을 맞추겠습니다.

## 더 알려주고 싶은 내용

이 프로젝트는 청각 장애인뿐 아니라 난청 사용자, 비원어민, 소음이 큰 환경의 참여자도 회의 논점을 따라갈 수 있게 만드는 것을 목표로 합니다. 향후 동의 화면, 전체 로컬 전용 모드, 민감정보 필터, Action Item/Decision Log 리포트, 패키징을 추가해 누구나 자체 운영할 수 있는 공개 접근성 도구로 발전시키겠습니다.
